# First-time authentication setup
Approved in chat: email signup requires MuntiCares password and a Brevo-delivered code. First Google login also requires password creation and an additional email code before portal access. Returning users may use Google or their MuntiCares password. Existing administrator access remains available.
Use Supabase Auth OTP delivery via existing Brevo SMTP, not a second Brevo API integration. Signup and magic-link templates display the OTP instead of a link. Google setup uses an authenticated Edge Function to set password, issue OTP, verify the OTP belongs to the signed-in account, then persist server-owned completion. UI gate prevents navigation to the portal before setup. Proposed broad restrictive policies were rejected by automatic approval review due to service-disruption risk; existing application, Storage and Realtime policies remain unchanged. Full enforcement against direct API calls remains outside the deployed change pending explicit approval. Codes are never stored in app tables or logged. Resend uses a cooldown and Supabase limits; failed verification cannot unlock access. Existing Google accounts without passwords require setup. Existing confirmed email/password accounts remain complete.
